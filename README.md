# Dan Cellucci

Founder-operator for 18 years: restaurants, a bar, a salon, and a craft cannabis brand in Maine. Now building AI sales systems for founder-led wholesale producers.

I build on my own businesses first. Every tool here started as a real problem in my own sales.

## Running now
An AI sales desk for my own wholesale brand: a daily pull of order data, reorder tracking for every account, a ranked morning call list with drafts I approve, and a phone app where I log every call. Private for now while I measure results. An open-source version is coming.

## Open source
- [Wholesale AI Context Kit](https://github.com/dlcellucci/wholesale-ai-context-kit): a context file template that stops AI from guessing prices, products, and account data
- [B2B Lead Enricher](https://github.com/dlcellucci/b2b-lead-enricher-ai): turns a company's website into a short summary, likely pain points, and 3 cold email drafts. Python, OpenAI, 54 tests.

## Coming next
- Producer Sales Desk kit: reorder tracking and daily call planning for any producer selling repeat orders to retailers
